# LinkedIn drafts

Every Friday at 7 PM, a draft post about the week's work from your commits. Code: [server/modules/linkedin.mjs](../server/modules/linkedin.mjs), page: `/linkedin`.

- **Drafts only:** nothing is ever posted automatically. Approve and copy on the hub, then paste into LinkedIn.
- Private repos are relabelled "project N" before anything reaches the LLM; drafts mentioning blocked words (employer, secrets, private repo names) are thrown away.
- Needs a read-only GitHub token on the phone to include private work.
