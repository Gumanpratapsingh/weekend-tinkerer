# Job Agent — privacy policy

*Last updated: 8 October 2026*

Job Agent is a personal tool run by Guman Pratap Singh on his own phone server. It has exactly one user: its owner.

**What it handles.** Job listings from public job boards; the owner's own resume, answers to application questions,
and recruiter emails in the owner's mailbox; WhatsApp messages between the agent and the owner's own number.

**Where it is stored.** Only on the owner's phone (a SQLite database). Nothing is sold, shared, or used for advertising.
Job descriptions and the owner's resume facts are sent to an LLM API (Groq) to score fit and tailor the resume.

**WhatsApp.** The agent only messages, and only accepts messages from, the owner's own WhatsApp number. Messages from
anyone else are ignored and not stored.

**Deletion.** Everything can be deleted by the owner at any time by removing the agent's data folder. Questions:
open an issue at https://github.com/Gumanpratapsingh/weekend-tinkerer.
